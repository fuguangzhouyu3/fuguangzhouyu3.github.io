执行评测

用例保存后，建议先执行单条用例确认输入、变量和预期结果，再加入测试集或测试 场景批量运行。不同执行入口的范围不同，先选择正确的维度可以减少排查成本。

按测试数据执行

执行单条用例

适合首次使用、刚修改过的用例或需要调试的失败用例。

  1. 进入 AI 工作台 -> Agent 评测 -> LLM 测试数据。

  2. 找到目标用例。

  3. 点击用例行上的“开始评测”。

  4. 等待系统自动创建测试任务。

  5. 从任务提示进入 Agent 测试任务。

  6. 记录任务 ID，并在结果页查看执行明细。

执行多个用例

适合已经完成单条验证，需要按筛选结果批量运行的场景。

  1. 在 LLM 测试数据列表中勾选目标用例。

  2. 点击“执行评测”。

  3. 确认选择范围和测试用户。

  4. 创建测试任务。

  5. 在任务列表中等待批量任务完成。

批量执行前要确认这些用例使用的 Agent、测试账号、业务变量和附件都可用；不要 把单企业夹具误用于其他企业。

按测试集执行

执行单个测试集

  1. 进入 LLM 测试集。

  2. 找到目标测试集。

  3. 点击测试集行上的“开始评测”。

  4. 确认自动创建的测试任务。

  5. 进入 Agent 测试任务查看明细。

执行多个测试集

  1. 在 LLM 测试集列表中勾选目标测试集。

  2. 点击“执行评测”。

  3. 确认多个测试集都使用兼容的测试用户和变量。

  4. 创建测试任务。

  5. 按测试集和用例维度查看结果。

按测试场景执行

测试场景适合把测试集按业务目标组合起来，并在一次执行后生成场景报告。

创建测试场景

  1. 进入 AI 工作台 -> Agent 评测 -> LLM 测试场景。

  2. 点击“新建”。

  3. 填写场景名称、执行用户和关联测试集。

  4. 保存后检查场景详情中的测试集范围。

手动执行测试场景

  1. 选择目标测试场景。

  2. 点击“开始评测”。

  3. 确认创建测试任务。

  4. 等待场景内用例执行完成。

  5. 打开生成的评测报告，并回到任务明细核对失败用例。

定时执行

当前材料标记的定时评测能力暂不作为本指南的可执行操作。是否支持定时任务、 定时频率和报告生成方式，需要按当前产品版本和企业配置核对；没有看到可用入口时， 不要通过手工修改配置或复制其他环境参数来推断支持。

执行前检查

  • 单条用例已经成功保存。

  • wholeBody__c 是可解析的 JSON 文本。

  • expected_result__c 的 validate_type 与场景一致。

  • 业务变量包含当前企业可用的记录和人员。

  • 附件已经上传到执行环境。

  • 期望的工具、Skill 和子 Agent 名称与当前 Agent 配置一致。

  • 批量执行范围不包含未完成或仅用于调试的草稿用例。
